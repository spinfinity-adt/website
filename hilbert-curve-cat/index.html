🔢 what is this?
A Hilbert curve is a fractal that visits every cell in a 2ⁿ×2ⁿ grid exactly once.

Each segment is coloured by sampling the cat photo — so the curve paints your cat using only connected lines.

Higher order = more detail but way more segments. Order 9 = 262,143 segments. 🐱
